# IVA por país (propuesta pendiente de ADR)

Tipos generales de IVA. Están contrastados con las fuentes del [ADR 003](../../../ai-workspace/02-arquitectura/003-iva-por-pais.md) (tipos vigentes a 28 de septiembre de 2026).

| País | Código | IVA |
| --- | --- | --- |
| España | ES | 21 % |
| Portugal | PT | 23 % |
| Francia | FR | 20 % |
| Alemania | DE | 19 % |
| Italia | IT | 22 % |

Se aplica el IVA del país del cliente, como pide el enunciado. No se modelan tipos reducidos, exenciones ni la inversión del sujeto pasivo en ventas B2B dentro de la UE. Se deja escrito como simplificación en el ADR.
